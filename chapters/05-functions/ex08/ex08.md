## Ejercicio 08: closure con estado

Creá una función `crearContador` que devuelva una función sin argumentos. Cada
vez que se invoque la función devuelta, debe incrementar y retornar un contador
privado.

En `main`, creá dos contadores independientes y llamá varias veces a cada uno.
Comprobá que cada contador conserva su propio estado y explicá qué variable
está capturando el closure.

No uses una variable global ni una estructura para almacenar el contador.
