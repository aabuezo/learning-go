## Ejercicio 24: agenda de contactos

Crear:

```go
type Contact struct {
    Name  string
    Email string
    Phone string
}
```

Usar:

```go
map[string]Contact
```

Donde la clave sea el email.

Implementar:

- agregar contacto
- buscar por email
- actualizar telefono
- borrar contacto
- listar todos
