## Ejercicio 18: slice de structs

Crear un tipo `User` y un slice de usuarios.

Definir operaciones para:

- agregar usuarios con `append`;
- buscar un usuario por ID y devolver `(*User, error)`;
- actualizar el email de un usuario encontrado;
- devolver un error cuando el ID buscado no existe;
- eliminar usuarios por ID y devolver el slice resultante;
- comprobar que eliminar un ID inexistente no modifica el slice;
- comprobar qué ocurre cuando hay varios usuarios con el mismo ID.

La búsqueda debe devolver un puntero al elemento del slice para que la modificación
del usuario encontrado actualice el elemento original.
