## Ejercicio 9: slicing

Dado:

```go
nums := []int{10, 20, 30, 40, 50, 60}
```

Crear slices derivados:

- primeros 3 elementos
- ultimos 3 elementos
- elementos del medio
- slice vacio desde `nums[:0]`
- slice completo con `nums[:]`

Modificar un elemento en un slice derivado y observar que pasa con el original.
