## Ejercicio 24: agenda de contactos

Crear:

```go
type Contact struct {
    Name  string
    Email string
    Phone string
}
```

Usar `map[string]Contact`, donde la clave sea el email.

Implementar:

- agregar contacto;
- buscar por email;
- actualizar teléfono;
- borrar contacto;
- listar todos.
