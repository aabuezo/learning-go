## Ejercicio 21: inventario simple

Crear structs:

```go
type Product struct {
    ID    int
    Name  string
    Price float64
    Stock int
}
```

Crear un inventario usando:

```go
map[int]Product
```

Implementar funciones para:

- agregar producto
- buscar producto por ID
- actualizar stock
- listar productos
- calcular valor total del inventario
