## Ejercicio 05: `nil` y valores opcionales

Creá una función que busque un `User` por ID y devuelva `*User`. Cuando no lo
encuentre, debe devolver `nil`.

Desde `main`, probá un ID existente y uno inexistente. Verificá el puntero
antes de desreferenciarlo y evitá que el programa termine con un panic.

Explicá cuándo un puntero `nil` puede representar correctamente "sin valor" en
una API y por qué no conviene devolver un puntero no válido.
