## Ejercicio 10: `GOMEMLIMIT` y configuración en tiempo de ejecución

Tomá el programa de asignaciones y ejecutalo con un límite blando de memoria:

```bash
GOMEMLIMIT=64MiB GODEBUG=gctrace=1 go run .
```

Compará el comportamiento con la ejecución sin `GOMEMLIMIT`. Usá una carga
pequeña y aumentala gradualmente; no intentes provocar un agotamiento de
memoria.

Como segunda parte, usá `runtime/debug.SetGCPercent` y
`runtime/debug.SetMemoryLimit` para cambiar la configuración durante la
ejecución. Registrá la configuración inicial y la nueva, y explicá por qué
`GOMEMLIMIT` es un límite blando y no una garantía exacta de uso de memoria.

Separá las conclusiones sobre el GC de las conclusiones sobre el sistema
operativo: el runtime administra la memoria de Go, pero una aplicación también
puede consumir memoria mediante C, `mmap` u otros recursos externos.
